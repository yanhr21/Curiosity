# Phase 00: Workspace Pivot

## Goal

Make the post-pivot workspace unambiguous and prevent old T-Rex-schema-first
work from being confused with the active Newton-native direction.

## Scope

- Active idea lives in `IDEA/idea.md`.
- Active plans live in staged folders under `PLAN/`.
- Active task tracking lives in staged folders under `TODO/`.
- Pre-pivot experiments and logs live under
  `legacy/2026-06-26_pre_pivot_archive/`.
- New experiments start from the fresh root `experiments/` and `logs/` trees.

## Completion Criteria

- New staged PLAN/TODO layout exists.
- Root README and AGENTS point to staged planning.
- Git ignore rules exclude large data, checkpoints, environments, caches,
  external clones, and legacy artifacts.
- Initial cleaned repository commit is pushed or a concrete push blocker is
  reported.
